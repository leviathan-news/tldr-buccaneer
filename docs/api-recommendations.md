## Missing Endpoints

### 2. Get User's Yaps by Wallet Address

**Proposed Endpoint:** `GET /api/v1/wallet/{address}/yaps/` or `GET /api/v1/user/{user_id}/yaps/`

**Why It's Needed:**
- Bot developers need to verify their posts went through
- Users want to see all comments from a specific wallet
- Analytics and leaderboard features require per-user yap queries

**Current Workaround:**
- Must iterate through all articles and check each one's yaps
- Very slow and inefficient for large datasets
- No way to get a user's complete comment history

**Suggested Parameters:**
- `limit` / `per_page`: Pagination
- `page`: Page number
- `sort`: `new`, `top`, `old`
- `tags`: Filter by tag (e.g., `tldr`, `alternate-headline`)

**Example Response:**
```json
{
  "count": 42,
  "results": [
    {
      "id": 24255,
      "text": "TL;DR summary...",
      "parent_id": 24178,
      "parent_headline": "Article headline...",
      "tags": ["tldr"],
      "created_at": "2026-01-30T20:06:35Z",
      "score": 5
    }
  ]
}
```

### 3. Get User Profile by Wallet Address

**Proposed Endpoint:** `GET /api/v1/wallet/{address}/` or `GET /api/v1/user/lookup/?address={address}`

**Why It's Needed:**
- Verify profile settings (display_name, bio) were applied correctly
- Look up other users' public profiles
- Bot health checks

**Current State:**
- `GET /api/v1/wallet/me/` exists but requires authentication
- No public endpoint to look up profiles by address
